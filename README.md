# NPC 网络穿透 · 群晖套件

把 [NPS](https://github.com/ehang-io/nps) 内网穿透客户端 npc 打包成群晖套件。安装后，在 DSM 里用图形界面就能管理，不需要 SSH 登录敲命令。

## 功能

- **支持 DSM 6 和 DSM 7**：两个系统各有一个安装包。
- **同时支持 x86_64 和 arm64**：安装包里两个版本的 npc 都有，装上后会自动选对应的那个。
- **在 DSM 桌面里以窗口打开**：从主菜单点开即可，不会新开浏览器标签页。
- **两个独立服务**：可以同时连两个 NPS 服务端，也可以只开一个。两个服务互不影响。
- **服务名称可以自定义**：比如改成"家里"、"公司"，方便区分。
- **直接粘贴命令**：把服务端给的完整命令（如 `./npc -server=1.2.3.4:8024 -vkey=xxxx -type=tcp`）原样粘进去就行，前面的 `./npc`、`sudo`、`install` 会自动去掉。
- **参数默认隐藏**：vkey 等参数平时显示成圆点，点一下输入框才显示。
- **开机自启**：点过"保存并启动"的服务，NAS 重启后会自动启动；点"停止"的服务则不会。
- **意外退出自动重启**：npc 进程意外退出时会自动拉起。如果一启动就退出（比如参数写错），重启间隔会逐渐拉长，避免反复重启。
- **运行状态**：界面上能看到每个服务是运行中、连接异常、正在重启还是已停止，以及已经运行了多久。
- **运行日志**：可以直接在界面里查看和清空日志。日志超过 1MB 会自动截断，不会占满硬盘。
- **升级保留配置**：升级套件后，已保存的参数不会丢。

## 安装

1. 从 Releases 下载与你的 DSM 版本对应的 `.spk` 文件。
2. 打开套件中心，选择"手动安装"，然后选中下载的文件。
3. DSM 6 用户需要先到 套件中心 → 设置 → 常规 → 信任层级，选择"任何发行者"。
